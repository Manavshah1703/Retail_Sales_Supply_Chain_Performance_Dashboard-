# Retail Sales & Supply Chain Performance Dashboard

## Project Overview
This project analyzes retail sales and supply chain performance using Excel and Tableau. 
The goal is to identify trends, evaluate performance, and provide actionable business insights.

## Tools Used
- Microsoft Excel (data cleaning and analysis)
- Tableau (interactive dashboard creation)
- PowerPoint (business presentation)

## Project Structure
- Data: Excel dataset used for analysis
- Tableau_Dashboard: Interactive Tableau workbook
- Presentation: Executive summary presentation
- Screenshots: Dashboard visuals

## Key Insights
- Identified top-performing products and regions
- Analyzed sales trends across time
- Evaluated supply chain performance metrics

## How to Use
1. Open the Excel file to view cleaned data.
2. Open the Tableau file to explore interactive dashboards.
3. Review the PowerPoint for summarized insights and recommendations.
